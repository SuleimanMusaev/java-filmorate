# java-filmorate

## 🎬 О проекте
java-filmorate — это REST-сервис (бекенд) для соцсети оценки фильмов, вдохновлённой системой «рекомендаций среди друзей». Сервис позволяет пользователям регистрироваться, добавлять друзей, оценивать фильмы и ставить лайки.

## Ссылка на диаграмму:
- https://github.com/SuleimanMusaev/java-filmorate/blob/main/db-diagram/Database_Diagram.png

### Возможности:
- CRUD для пользователей и фильмов;
- Добавление в друзья, подтверждение дружбы, получение списка друзей;
- Ставить лайки на фильмы;
- Получения рекоменлации от друзей
- Лента последний событий
- Получить список общих фильмов
- Возможность удаления пользователя или/и фильма
- Поиск по названию фильмов и по режиссёру
- Возможность оставить отзыв о фильме
- Самые популярые фильмы по жанру или за определенный год
- REST API для взаимодействия с фронтендом или внешними клиентами.

### Примеры работы с приложением:
```
Создание пользователя:
{
  "login": "dolore",
  "name": "Nick Name",
  "email": "mail@mail.ru",
  "birthday": "1946-08-20"
}

Добавление фильма:
{
"name": "nisi eiusmod",
"description": "adipisicing",
"releaseDate": "1967-03-25",
"duration": 100
}

Получить список фильмов:
GET /films

Получить список друзей:
GET /users/{{id}}/friends

Посмотреть жанры:
GET //genres

И многое другое...
```
